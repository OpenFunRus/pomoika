# ElevenLabs — гайд (веб-версия) для звуков и музыки Vintage Story

> Напарница FeralZombie. **Только веб-интерфейс** ElevenLabs (сайт/приложение), без API и прогов.
> Актуально на **2026** (последняя версия). Цель: на подписке сгенерировать **все звуки (SFX)** и **всю музыку** для замены оригинальных ассетов (пути — в [README.md](./README.md), промпты — в [Promts.md](./Promts.md)).

---

## 0. Коротко

- Работаем в **веб-приложении** (ElevenCreative). Вход: **`elevenlabs.io`** → войди в аккаунт.
- Два продукта нужны:
  - **Sound Effects** — `elevenlabs.io/app/sound-effects` (или в левом меню **Playground → Sound Effects**). Для ~600 игровых звуков.
  - **Music** — `elevenlabs.io/app/music` (Eleven Music). Для 41 трека + пещер.
- У ElevenLabs **один общий пул кредитов** на месяц, он тратится на всё вместе.
- **Важно для игры:** игра читает аудио только в **WAV (RIFF)** или **OGG** — **MP3 НЕ воспроизводится** (декодер шнифует `RIFF`/OGG, см. [README §4](./README.md)). Поэтому в скачивании выбирай **WAV** (или конвертируй MP3 → OGG, §5).

## 2. Sound Effects — как пользоваться в вебе

### 2.1 Где и что нажимать
1. Открой **`elevenlabs.io/app/sound-effects`** (или в левом сайдбаре **Playground → Sound Effects**).
2. В поле **prompt** впиши описание (макс **450 символов**) — из [Promts.md](./Promts.md).
3. Настройки справа:
   - **Duration** — длина (0.5–30 с) или **Auto** (ИИ сам). Для игры ставь явно: одиночные 0.5–1.5с, амбиент 20–30с.
   - **Looping** — тумблер **бесшовного цикла** (включай для амбиента: ветер, дождь, вода, огонь, пещерные дроны).
   - **Prompt influence** — «как строго ИИ следует промпту» (слайдер). Выше = буквально; ниже = больше вариаций.
4. Нажми **Generate** (стрелка). За раз генерируются **4 варианта** промпта.
5. Прослушай, выбери лучший. Можно:
   - **upscale** (улучшить качество) выбранного,
   - изменить prompt/настройки и **сгенерить заново** (снова 4 варианта),
   - сохранить понравившийся **звёздочкой** (Favorites).

### 2.2 Скачивание (и выбор формата — важно)
- Вкладка **History** → для каждого сгенеренного звука иконка **скачивания**.
- Выбери формат:
  - **WAV (48 kHz)** → **бери этот** — игра **воспроизводит WAV напрямую**, без конвертации. Идеально для одиночных звуков.
  - **MP3 (44.1 kHz)** → для loop-амбиента иногда дают только MP3; MP3 игре **не подходит** (см. §0) — конвертируй (§5).
- **Имя файла:** при сохранении назови **точно как в игре, без `.ogg`** (напр. `walk_grass1`), потом положи в нужную папку `assets/<pack>/sounds/...` (см. [Promts.md](./Promts.md) и [README §4](./README.md)).

### 2.3 Как писать промпт (лайфхаки)
- **Коротко и конкретно.** 4 столпа: **материал + действие + среда + стиль/термин**.
  - Пример: `high-quality foley footsteps on wet grass, soft crunching, one-shot`.
- **Один звук = один промпт.** Для последовательностей генерируй **слои по отдельности**.
- **Саунд-сеты** (напр. `walk/grass1..3`): генерируй **несколько разных** — либо один промпт 4 раза (берёшь 3 лучших из 4 вариантов), либо чуть разные формулировки. Игра сама выбирает случайный из набора (см. `soundconfig.json`).
- **Полезные термины** (модель их понимает): `impact`, `whoosh`, `ambience`, `one-shot`, `loop`, `drone`, `braam`, `glitch`, `foley`, `cinematic`, `horror`.
- **Не тот звук?** Подними prompt influence, добавь конкретные термины, или пересчитай формулировку.

## 3. Music — как пользоваться в вебе

### 3.1 Где и что нажимать
1. Открой **`elevenlabs.io/app/music`** (Eleven Music).
2. **Модель**: в выпадающем списке выбери **Music v2.5** (лучшая, по умолчанию; v2 тоже есть).
3. **Prompt** — текстовое описание трека (5 вопросов: **жанр + настроение + инструменты + темп/BPM + эпоха**). Промпты — в [Promts.md §B](./Promts.md).
   - **Важно:** добавь **`instrumental`** / **`no vocals`** — в игре нет вокала.
4. **Audio Reference** (по желанию): кнопка **`+ Reference`** в секции Prompt → загрузи короткий трек (до ~30с), чтобы задать стиль/тембр/грув. (Для игры можно пропустить.)
5. **Настройки:**
   - **Variants** — сколько вариантов за генерацию.
   - **Duration** — длина: **30с / 1м / … / до 10 минут** или **Auto**. Для фоновых треков ставь **1–3 мин**.
6. **Generate** → прослушай варианты.
7. **Доработка:**
   - **«+ Add Section»** — наращивать трек по секциям, если нужен длинный.
   - Можно править отдельные секции/стили.
8. **Download** — скачать файл. **Share** — ссылка с визуализатором.

### 3.2 Скачивание (и формат)
- По умолчанию музыка скачивается как **MP3 (44.1kHz, 128–192kbps)** → игре **не подходит** (см. §0).
- **Music v2.5** даёт **lossless** скачивание (без потерь) на всех планах (Free 5/день, Pro 400/мес) — бери **lossless (WAV)** → игра воспроизводит напрямую.
- Если скачался **MP3** → конвертируй в OGG/WAV (§5).
- **Имя** = `file` из `musicconfig.json`, без `.ogg`, в `assets/<pack>/music/`.

### 3.3 Как писать промпт (лайфхаки)
- Промпт отвечает на **5 вопросов**: **жанр, настроение, инструменты, темп (BPM), эпоха/продакшн**. Что не указал — ИИ выберет «среднее».
- **Указывай BPM и тональность** буквально: `60 BPM, in A minor` — модель держит числа точно.
- **Для ambient/фон** — «упражнение в исключении»: укажи BPM/тональность и **что запрещено**:
  - `Ethereal ambient soundscape, slowly evolving pads, distant bells, 50 BPM, in A minor, no rhythm, no percussion, no melody, instrumental`.
- **Бесшовный луп** (пещерные `deepunderground/*`): пропиши в промпте `seamless loop, N bars, BPM, key, no ending`, и задай нужную длину (напр. 30с).
- **Ключевое `solo`** — изоляция одного инструмента (для наборов `instrument/` и `voice/`).
- Если промпт слишком «средний» — добавь конкретики по инструментам и настроения; если слишком «песенный» — усиливай `no melody / no percussion / instrumental`.

## 4. Практический порядок работы (веб)

1. Открой [Promts.md](./Promts.md) — бери промпт под нужный файл.
2. **SFX:** `app/sound-effects` → prompt → duration → (loop если амбиент) → **Generate** (4 варианта) → выбираешь лучший → **History → скачиваешь WAV 48kHz** → сохраняешь с именем из игры.
3. **Музыка:** `app/music` → модель **v2.5** → prompt (`instrumental`) → duration 1–3м → **Generate** → **Download (lossless/WAV)** → сохраняешь с именем из `musicconfig.json`.
4. Положи файл в нужный путь `assets/<pack>/sounds|music/...` (имя **без** `.ogg`).
5. Перезапусти игру, проверь по чек-листу [README §6](./README.md).

> Сети с несколькими файлами (напр. `walk/grass` — 3 файла): сделай 1–2 генерации (4 варианта каждая) и бери 3 разных. Это даст игре «случайный из набора».

## 5. Единственный шаг «вне сайта» — формат файла

Игра читает **WAV** (RIFF) и **OGG** (Vorbis). **MP3 не воспроизводится.**
- Если скачал **WAV** (SFX 48kHz / Music lossless) — **конвертация не нужна**, кладёшь как есть (имя без `.ogg`).
- Если скачался **MP3** (loop-SFX или музыка по умолчанию) — конвертируй в **OGG** (или WAV). Лёгкие варианты:
  - **Audacity** (бесплатно): *File → Open* (MP3) → *File → Export* → **WAV** или **Ogg Vorbis**.
  - или ffmpeg одной строкой: `ffmpeg -i in.mp3 -c:a libvorbis -q:a 5 out.ogg` (для OGG) / `ffmpeg -i in.mp3 -c:a pcm_s16le out.wav` (для WAV).

> Держи исходники в `FeralZombie/raw/`, готовые в `FeralZombie/out/`, а копируй в `assets/`.

## 6. Лайфхаки и подводные камни (веб)

- **Кредиты общие:** не трать зря — генерируй нужные пачками, не «на пробу» всё подряд.
- **Free = только личное** (музыка — с указанием ElevenMusic). Для публикации мода — бери **Creator+**.
- **SFX: 4 варианта за генерацию** — это твой «бесплатный» набор вариаций; для сета бери 3 разных.
- **Выбирай WAV при скачивании SFX** — тогда не нужно конвертировать.
- **Музыка: ставь модель v2.5 и бери lossless/WAV** — иначе будет MP3 и нужна конвертация.
- **Длина:** одиночные звуки — 0.5–1.5с; амбиент — 20–30с + loop; музыка — 1–3 мин (пещерные лупы — ~30с).
- **Имя = без `.ogg`**, точь-в-точь как в конфиге/оригинале (иначе «Could not load sound» в логе).
- **Питч/громкость** в игре подстраивает движок — генерируй звук в нормальном тембре и громкости, без экстремумов.
- **Один промпт на один звук.** Не пытайся «всё в одном» — разбивай на слои.

## 7. Чек-лист «сгенерировал → в игру»

- [ ] Промпт короткий, 4 столпа (материал+действие+среда+стиль) — для музыки 5 вопросов.
- [ ] **SFX:** duration задан, амбиент — с **Looping**. **Music:** `instrumental`/`no vocals`, модель **v2.5**.
- [ ] Скачал в **WAV** (SFX 48kHz / Music lossless) — или сконвертировал MP3 → OGG/WAV (§5).
- [ ] Имя файла — **без `.ogg`**, совпадает с оригиналом/конфигом.
- [ ] Положен в правильный путь (`assets/<pack>/sounds|music/...`).
- [ ] Игра **перезапущена**, в логе нет `Could not load sound`.
- [ ] Проверил в игре (см. [README §5](./README.md)) — звучит как ожидается.
